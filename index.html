// Setup Instructions

1. Install Dependencies

# Install Node.js 16+ if needed # Then install yt-dlp and ffmpeg: # macOS (Homebrew) brew install yt-dlp ffmpeg # Ubuntu / Debian sudo apt install ffmpeg pip install yt-dlp # Windows (winget) winget install yt-dlp ffmpeg

2. Run the Backend

# Install Node dependencies npm install # Start the server npm start # Or with auto-reload (dev mode) npm run dev # Server runs at: http://localhost:3001

API Endpoints

# Health check GET /api/health # Get track metadata GET /api/info?url=<URL> # Download track GET /api/download ?url=<URL> &format=MP3 &bitrate=320

3. Open the Frontend

# Place index.html in the # backend/public/ folder, then # visit in your browser: http://localhost:3001 # Or open index.html directly # and set the API URL above # to your server address.
